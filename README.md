# Alunos API

API RESTful para gerenciamento de alunos construída com .NET 9.0.

## 🐳 Executando com Docker

Este repositório contém um `docker-compose.yml` que orquestra todo o ambiente (Banco, API e Frontend).

Para rodar tudo usando as imagens publicadas:

```bash
docker-compose up -d
```

- **Frontend**: http://localhost:3000
- **API**: http://localhost:5000/swagger

## 📋 Pré-requisitos

- [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)
- [Docker](https://www.docker.com/get-started)
